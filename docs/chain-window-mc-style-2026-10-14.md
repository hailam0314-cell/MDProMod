# 连锁窗口改成 MC 风格：格子选卡 +「连锁 / 取消」（2026-10-14 晚）

## 改之前

`ChainChoiceScreen` 是每张卡下面各挂一个「接连锁」按钮、中间画竖线、卡片上标"第 N 环"，
底部再来一个「放弃（不接连锁）」——文字多、控件多，和别的窗口（选卡清单、卡堆清单）
风格也不统一。

## 改之后

**一个标准 MC 窗口**（和选卡 / 卡堆 / 决策窗口同一套 `McPanel` 绘制 + 原版按钮）：

- 标题居中写 **「连锁」**；强制连锁时左上角一个小字「必须接」。
- 候选卡排在格子里（凹槽 + 卡图，最多 5 列自动换行）；**左键点一张选中**（金框），
  鼠标悬停出卡名，卡片左上角一个小数字表示这是第几环。`code <= 0`（对方里侧等不可见信息）
  显示卡背 + "里侧卡片"。
- 底部只有两个按钮：**「连锁」**（提交选中的那一张）和 **「取消」**（放弃，即 `-1`）。
  - 候选只有一张时自动选中，「连锁」直接可点；
  - 没选卡时「连锁」是灰的；强制连锁时「取消」是灰的（核心不接受放弃）；
  - ← / → 键也能换选哪一张。
- 不允许 ESC 直接关：结束前必须给核心一个答案，否则对局会停在提示上。

连锁窗口的观感（窗口位置 / 卡大小 / 两个按钮的字号），以及"点卡 → 点连锁"是否顺手。
