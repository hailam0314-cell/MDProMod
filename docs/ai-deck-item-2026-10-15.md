# 「人机卡组」物品：选择对手人机（2026-10-15）

## 起因

以前**远半场（对手区）的卡组是自动补的**：`DuelSessionManager.ensureAiDeck()` 一看
`p2` 没有卡组，就把系统属性 `mdpromod.aiDeck`（默认 `AI_BlueEyes`）的卡组绑上去。
所以往对手区放什么都一样——开打永远是青眼白龙人机。

现在改成：**远半场必须由玩家放「人机卡组」物品**，放谁就和谁打。

## 新增物品

- `mdpromod:ai_deck`，显示名「人机卡组 · 〈所选人机〉」（`en_us`: AI Deck）。
- 模型沿用卡盒（`item/generated`），**图标是蓝色的卡盒**：
  `textures/item/ai_deck_icon.png` 由 `tmp/make_ai_deck_icon.py` 从
  `card_case_icon.png` 按亮度映射到蓝色系生成，保留 alpha。
- 已加入创造模式「MDProMod 决斗」标签页。
- 右键打开界面（见下）；放到决斗盘**远半场**即开打。

## 界面（只读）

`AiDeckScreen`：

- 上方一行：`◀ [人机名 ▾] ▶`。点中间的名字**展开下拉列表**（一次 8 条、滚轮翻页），
  列表里当前那个人机带 ✓；左右箭头也能直接前后切换。
- 名字下面显示 `bot.conf` 里那句话描述（如「青眼卡组。」）。
- 下方是这副人机卡组的**预览**：主卡组 / 额外卡组 / 副卡组三区，按行铺卡图，
  鼠标悬停显示卡名。
- **不能加卡、不能减卡**——这一栏只有一个「完成」。
- 换人机立刻写回物品 NBT（`AiDeck` / `AiDeckLabel` / `AiDeckDesc`），
  所以物品名和 tooltip 不需要读磁盘。

## 谁是人机：`AI_*.ydk` + `bot.conf`

`AiDeckCatalog` 的做法：

1. 以**磁盘上的卡组文件**为准：扫 `Data/Windbot/Decks/AI_*.ydk`（本机 57 个）。
2. 去 `Data/locales/zh-CN/bot.conf` 找显示信息：
   `!标题` + `Name=人机名 Deck='卡组名' Dialog=人格` + 一句话描述。
   卡组名按下划线规则规范化成文件名（去空格、`'Level VIII'` → `AI_Level8.ydk`），
   并按**大小写不敏感**匹配（`Time Thief` 对应磁盘上的 `AI_Timethief.ydk`）。
3. 匹配不上的卡组用文件名兜底，不会因此消失。

例：`AI_BlueEyes.ydk` → 「复制植物-青眼」/ 人机名「复制植物」/ 人格 `Universal.zh-CN` /
描述「青眼卡组。」。

## 开局流程的变化

| 动作 | 现在 |
| --- | --- |
| 自己的卡盒放**自己这侧** | 照旧绑定 p1 |
| 自己的卡盒放**对侧** | **拒绝**，提示「等待对手选择卡组」 |
| 人机卡组放对侧 | 读那副 ydk、绑定 p2、记住人机身份（键/显示名/人格） |
| 人机卡组放自己这侧 | 拒绝，提示「人机卡组要放到对面那半场」 |
| 点绿色开始按钮但对面没放 | 提示「等待对手选择卡组」（**不再自动补青眼**） |

开局时 `startForField` 用**玩家放上去的那副人机的 ydk + 人格**启动宿主；
`DuelHostProcess.sendStart` 现在优先用传进来的 `deck1` 路径，系统属性只作兜底
（`-Dmdpromod.aiDeck` 仍是"没放人机卡组时"的默认值）。
决胜后 `resetForNewDuel` 会卸掉 p2，需要重新放人机卡组。

## 尚未做 / 待实机确认

1. **实机没跑过**：放人机卡组 → 开局 → AI 是否按选的人格出牌，需要进游戏确认一次。
2. 界面是"差不多像编辑卡组"的紧凑版（固定网格、不滚动）；卡特别多时额外/副卡组
   会挤在一屏里，如果看着别扭再给三区加独立滚动。
3. 敌人卡组目前**不校验禁限**（人机用的是预设卡组，以前 `ensureAiDeck` 也不校验）。

## 界面改版：MC 风格 + 第二层选人机（同日）

第一版界面被反馈"不太美观"，重做：

### 第一层 `AiDeckScreen`（卡组预览）

整套用项目现成的 MC 风格组件 `McPanel`（面板 / 凹槽 / 卡图 / 金框悬停），和编辑卡组同一套观感：

```
┌─ 人机卡组 ──────────────────────────┐
│  ◀ [ 复制植物-青眼 ▾ ] ▶            │  ← 点中间打开第二层
│            青眼卡组。               │  ← bot.conf 的描述
│  [▶ 主卡组 40] [额外卡组 15] [副卡组 0] │  ← 分区标签（一次看一个区）
│  ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐ │
│  └──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘ │  ← 凹槽 + 卡图，悬停金框
│  …（固定 3 行，滚轮翻页）…            │
│          第 1/2 页 · 共 40 张         │
│                [ 完成 ]              │
└─────────────────────────────────────┘
```

**尺寸自适应**：卡图大小按窗口高度算（固定 3 行），所以 GUI scale 3 的小窗口
（427×240）也不会溢出；实测过 640×360 与 427×240 两种。

### 第二层 `AiDeckPickerScreen`（选人机）

点顶部名字进入，两列列表（最多 9 行/页，滚轮翻页），当前那个带 ✓，
悬停某一条时底部显示它的一句话描述；点一条即选中并**退回第一层**（立刻看到这个人的卡组）。
底部是 `◀ ▶` 翻页 + `返回`。
