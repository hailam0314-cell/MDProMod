# 决斗盘绑定流程与指令可用性（2026-10-13）

## 反馈
主人测试时「指令均无反应」，原因是之前只有两条隐式路径会绑定决斗盘
（`/mdpromod duel start` 自动抓 32 格内最近的场地、`/mdpromod field bind`），
没有绑定的时候手牌 HUD / 世界手牌实体都不会出现，看起来就像指令没生效。

## 新的正门流程
1. **放场地**：手持决斗盘右键地面 → 16×14 方块、朝向自动吸附 90 度。
2. **空手右键场地** → 绑定（并回显当前状态）：
   「已绑定决斗盘（空手右键）。现在用卡盒右键这里放下卡组；本侧还没有卡组」。
3. **卡盒右键场地** → 校验 40–60 / ≤15 / ≤15 / 禁限后放下卡组：
   - 该侧卡组堆出现（厚度按张数）；
   - 同时自动把这块场地绑到玩家（不必先空手绑一次）；
   - 卡组被记进会话（`pendingDeck`），**不拿在手上也能开对局**。
4. **`/mdpromod duel start`** → 优先用背包里的卡盒，没有卡盒就用放在场地上的卡组；
   两者都没有时提示「没有可用的卡组：背包里没有卡盒，也没有用卡盒右键放下的卡组」。

## 指令可用性
- 之前整棵 `/mdpromod` 命令树都要求权限等级 2（`hasPermission(2)`），
  在没开作弊 / 不是 OP 的世界里会直接「无反应」。
- 现在去掉了这个门槛：所有 `/mdpromod` 子命令任何玩家都能用（原型阶段方便测试）。

## 手牌自检
- `/mdpromod hand test` 现在要求 48 格内有决斗盘（没有就明确报错告诉你先放场地），
  执行后会：绑定该场地 → 在己方一侧生成 6 张手牌实体 → 同时推屏幕 HUD。
  这是不跑对局也能验证「世界手牌 + 防偷看」的最快路径。
- `/mdpromod hand clear` 同时清掉世界实体与 HUD。
- `/mdpromod hand reveal` 切换对手侧手牌的公开状态（验证「未公开只看到卡背」）。
