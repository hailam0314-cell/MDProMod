# 决斗盘 v2（2026-10-13）

## 需求
1. 放置后必须与方块对齐，不能斜着。
2. 放下后先只显示决斗盘本身，玩家放入卡组后才出现卡组 / 卡片模型。
3. 场地要足够大。

## 场地几何
- 尺寸从 **8 x 7 方块** 放大到 **16 x 14 方块**（面积 4 倍），
  贴图 2048 x 1792 px，密度仍是 128 px / 方块。
- 所有卡片区中心坐标都是 **16 的整数倍**（1 方块 = 16 模型单位），
  放到方块中心后每个区域正好压在一格方块中心上：
  - 怪兽区 x = -64 / -32 / 0 / 32 / 64，z = ±32
  - 魔陷区同上 x，z = ±64
  - 主卡组 (96, 64) / 额外卡组 (-96, 64) / 墓地 (96, 32) / 除外 (96, 0) / 场地魔法 (-96, 32)
  - 额外怪兽区 (±32, 0)，阶段条 z = ±102
- 生成器：`assets/duel_field/build_duel_field_assets_v2.py`
  输出 `textures/duel_field_atlas_v2.png` + `duel_field_layout_v2.json`，
  已覆盖到模组资源的 `textures/entity/duel_field_atlas.png` 与 `data/mdpromod/duel_field_layout.json`。
- 顺手修了两个老问题：
  - 老贴图底下那排色板也被 UV 0–1 画到了场地边缘；新贴图就是纯场地表面，没有色板条。
  - `zoneWorldPosition()` 以前不理会决斗盘朝向，旋转过的场地放卡会偏；现在按朝向做旋转。

## 放置对齐
- `DuelFieldItem.snapYaw()` 把朝向吸附到最近的 90 度：物品右键放置与
  `/mdpromod field place` 都走这个函数，不会再出现斜着的场地。
- 放置位置取点击方块的中心（+0.5 / +0.5），配合整数倍区域坐标，
  卡片落点正好在方块中心。

## 先场地、后卡组
- 场地实体新增同步字段：近半场 / 远半场各自的「是否已放卡组」、卡组名、主卡组张数、额外卡组张数。
- 渲染只有两种情况：
  - 没放卡组：只画场地贴图。
  - 放了卡组：在该侧的主卡组 / 额外卡组区域叠出卡背堆，层数按张数算
    （主卡组每 10 张一层、最多 6 层；额外卡组每 5 张一层、最多 3 层）。
- 放入方式：
  - 手持卡盒右键决斗盘 → 校验 40–60 / ≤15 / ≤15 / 禁限后绑定到你所在一侧；
  - 或者 `/mdpromod field bind`（把背包里的卡盒绑到最近的决斗盘）。
- 实体大小从 8 调到 16（命中判定跟着场地走），卡片实体半径 0.5 → 1.0，
  场上卡片尺寸同步放大到 13.75 x 20 模型单位（约 0.86 x 1.25 方块）。
