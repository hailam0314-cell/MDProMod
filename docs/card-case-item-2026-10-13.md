# 卡盒物品化（2026-10-13）

## 目标
把卡盒从「世界实体」升级成「手持物品」：右键打开卡组编辑器，编辑结果全部写进物品自身，
物品名称跟随卡组名；开始决斗时直接拿这件卡盒当卡组使用。

## 已实现

### 物品行为（`CardCaseItem`）
- 右键（对空气或方块）：服务端发送 `CardCaseOpen` 数据包，客户端打开卡组编辑器界面。
- 潜行 + 右键方块：仍然放置原来的卡盒实体，并把物品里的卡组复制给实体。
- `getName(ItemStack)` 重写：物品名称 = 卡组名（没有保存过卡组的空卡盒显示默认名「卡盒」）。
- 悬停提示：主/额外/副数量、合法性结论（绿色合法 / 红色列出前两条问题）、操作提示。

### 数据结构
- 卡组存在物品 NBT 的 `Deck` 标签里（`DeckData.save()`：name / main / extra / side 四段）。
- 每次加卡、减卡、改名都由服务端写入 NBT，并立刻回发一份快照给客户端。
- 服务端还会调用 `player.inventoryMenu.broadcastChanges()`，让快捷栏/背包里的物品名称立刻刷新。
- 卡表（`data/mdpromod/cards.json`）这一轮补上了 `desc`（效果文本）和 `ot`（卡池范围）：
  由 `tools/generate_cards_json.py` 从 `cards.cdb` 的 `texts.desc` 重新生成，
  15019 张卡，JSON 6.7 MB（jar 里压缩后约 1.3 MB）。

### 界面（`CardCaseScreen` + `CardSearchScreen`，第三版：按操作习惯分区）
第二版把按钮和文字挤在一行，压得太满，这一版按「看卡 / 编卡 / 找卡」重新分区：
- **左：卡片详情。** 选中卡的完整卡图（按栏宽等比缩放，最大 112×163），下面依次是卡名、
  类型行（怪兽 · 光 · 8 星 · 龙族）、攻守，然后是一个固定的效果文本框：字号缩到 0.72 倍、
  自动换行、区域裁剪，鼠标滚轮滚动看完整效果文本。
  文本框一直延伸到面板底边（不再给按钮留位置），空间不够时卡图自动缩小给文本让位。
  - 卡名 / 类型行 / 攻守三行按文字长度自动缩放：够宽就原样画，超宽就等比缩小
    （卡名最低 0.55 倍、类型与攻守 0.6 倍），只有缩到下限仍放不下才用省略号。
  - 魔法·陷阱的类型行写子类名（通常魔法 / 速攻魔法 / 永续魔法 / 装备魔法 / 场地魔法 /
    仪式魔法 / 通常陷阱 / 永续陷阱 / 反击陷阱），不再和第三行重复。
- **中：当前卡组。** 主卡组 / 额外卡组 / 副卡组三块竖排，**每行固定十张卡图**，格子里是
  卡图、右下角数量、左上角限制 1/2 的色块；块头显示「▶ 主卡组 42/60」，点块头切换当前区，
  方向键区（▶）表示新卡加到哪里；左键点卡 = 选中看详情，右键 = 移除一张；滚轮按整行翻页，
  右下角显示当前页/总页数。每块区域的高度按 主 52% / 额外 24% / 副 24% 分配。
- **右：卡池检索。** 只有一行：搜索框（卡名或卡号）+「查找」按钮，下面是结果列表
  （小卡图 + 卡名 + 卡号 + 卡组内数量），左键点一行 = 加入当前区、右键 = 从卡组里移除一张，
  滚轮翻页；已生效的检索条件会显示成「条件 N 项」。
- **鼠标操作即全部操作**：详情栏不再放「加入 / 移除」按钮——卡池左键加入、右键移除，
  卡组里左键选中、右键移除一张，区头切换当前区。
- **顶栏只剩三样**：标题「卡盒」、卡组名输入框（回车保存）、「完成」按钮；不再堆导出/筛选按钮，
  导出改用 `/mdpromod case export`（开决斗时也会自动导出）。
- **第二层检索界面（`CardSearchScreen`）**：点「查找」后弹出独立窗口，按功能分组：
  种类（怪兽 / 魔法 / 陷阱 / 只看额外）、属性（光暗地水炎风神，可多选）、
  **魔陷种类**（通常魔法 / 永续魔法 / 装备魔法 / 速攻魔法 / 仪式魔法 / 场地魔法 /
  通常陷阱 / 永续陷阱 / 反击陷阱，可多选）、种族（26 个可多选按钮，按面板宽度 4–7 列）、
  数值（等级 / 攻击 / 守备的上下限，留空不限）、其他（仅限制卡、排序：类型/等级/攻击/守备/卡号），
  底部固定「重置条件 / 取消 / 应用并返回」。
  - 面板高度按内容实际高度算（标题 22 + 内容 + 按钮区 30），内容装不下时**整块内容区可滚轮滚动**，
    右侧带滚动条，滚出可视区的控件自动隐藏，不会和底部按钮重叠。
  - 魔陷子类按卡表的类型位判定：速攻 `0x10000`、永续 `0x20000`、装备 `0x40000`、
    场地 `0x80000`、仪式 `0x80`、反击 `0x100000`；卡表里「通常魔法 / 通常陷阱」不带子类位，
    所以用自定义哨兵位表示（选了「通常魔法」= 匹配没有任何子类位的魔法）。
- 整体仍是 `#C6C6C6` 面板 + 白/深灰立体斜角 + 内凹物品栏槽位，没有外部素材依赖；
  卡图来自 `CardTextureCache`（`D:\MDProMod\runtime\card_textures_176x256_q80\<code>.jpg`），
  按可见格子数量按需加载。

### 校验（`DeckRules`）
- 主卡组 40–60，额外 ≤15，副 ≤15。
- 同一张卡（主 + 额外 + 副合计）数量不能超过限制。当写这份文档时是内置的 6 条小表
  （强欲之壶 / 死者苏生 / 羽毛扫 = 1，大岚 / 反射镜力 / 王宫通告 = 2，其余 3）；
  2026-10-15 起改成读 `lflist.conf` + `banlist.conf` 开关，见 `docs\banlist-config-2026-10-15.md`。
- 额外卡组专用卡（融合 / 同步 / 超量 / 连接）不能进主卡组，主卡组卡不能进额外卡组。
- ~~完整的 `lflist.conf` 禁卡表留到下一步接入。~~ 2026-10-15 已接入，见 `docs\banlist-config-2026-10-15.md`。

### 决斗入口（`DuelCommands`）
- `/mdpromod duel start`：优先取玩家背包里的卡盒，校验通过后导出
  `D:\MDProMod\runtime\decks\<卡组名>.ydk`，再用这份卡组启动无头决斗进程；
  没有卡盒或卡组不合法会直接报错并列出原因。
- `/mdpromod case give [卡组名]`：拿一个新的卡盒；带名字时会从 `runtime\decks` 或
  `D:\MyCardLibrary\mdpro3\Deck` 读入同名 `.ydk`。
- `/mdpromod case export`：把背包里的卡盒导出成 ydk，方便和 MDPro 互导。
- `/mdpromod case info`：打印卡盒里的卡组信息与校验结果。
