# 手牌 HUD（2026-10-13）

## 设计方案
按可视化稿「悬浮扇形」方案落地：

- 卡图浮在快捷栏上方，居中排列；牌少时宽松、牌多时自动收紧间距
  （≤5 张间距 38、6–7 张 26、≥8 张 20 逻辑像素）。
- 悬停：整张牌抬起 4px、放大 1.25 倍，并弹出 MC 原生 tooltip（卡名 / 类型行 / 攻守）。
- 左键：选中（金色描边）并显示动作栏提示；右键：弹出大图详情。
- 对手回合：整条手牌压暗（半透明黑罩），左上角标签变成「手牌 N · 对手回合」。
- 大图详情 `HandCardScreen`：左边卡图、右边「类型行 / 攻守 / 卡号」，下面是效果文本，
  字号 0.85、自动换行、区域裁剪、滚轮翻页；左键或右键或 Esc 关闭。

## 数据链路
- `DuelHostProcess` 现在解析出每名玩家**具体的手牌卡号**：
  - `Draw(90)`：`player(1) count(1) cards(4*count, 小端)` → 逐张加入手牌；
  - `Move(50)`：目标区域 `0x02`（手牌）→ 加入，来源区域 `0x02` → 移除；
  - `NewTurn(40)`：`player(1)` → 记录当前回合玩家，用来判断「你的回合 / 对手回合」。
  所有卡号都会先用 `CardRegistry` 校验，非法值直接忽略。
- `DuelSessionManager` 记录「决斗盘 + 玩家 UUID」，服务器每 tick 比对上次快照，
  有变化才发 `HandSync`（卡号数组 + 是否进行中 + 当前回合玩家）给该玩家客户端；
  对局结束时自动推一份空手牌，HUD 消失。

## 客户端
- `ClientHandBridge`：缓存快照、选中序号。
- `HandHudOverlay`：`RenderGuiEvent.Post` 里绘制，鼠标位置换算成 GUI 坐标做悬停判定；
  `InputEvent.MouseButton.Pre` 里拦截落在手牌上的左右键（左键选中、右键开详情），
  事件被吃掉后不会误触世界（不会挖方块 / 不会使用手上物品）。
- 打开任意界面（背包、卡盒编辑器等）时 HUD 自动隐藏，F1 隐藏 GUI 时也隐藏。

## 命令
- `/mdpromod hand test`：立刻推 6 张测试手牌（青眼白龙 / 灰流丽 / 死者苏生 /
  奈落的落穴 / 强欲之壶 / 增援），不用真开对局就能看 HUD 效果。
- `/mdpromod hand clear`：清空手牌 HUD。
- `/mdpromod duel start`：开对局时自动绑定决斗盘与手牌推送对象。
