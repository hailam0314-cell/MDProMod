# 空手蹲下右键收回决斗盘 / 卡盒（2026-10-15）

## 需求与手势

**空手（两只手都空）＋ 蹲下 ＋ 右键**：

| 对着什么 | 效果 |
| --- | --- |
| 决斗盘 | 收回决斗盘，物品回到背包 |
| 卡盒实体 | 收回卡盒（连里面那副卡组） |

手势放在卡 / 卡堆 / 按键**判定之后**：蹲着调阶段、翻卡的时候不能手一滑把整块盘收了——
想收就对着场地空白处蹲下右键。（第一版放在最前面，结果蹲着右键点阶段键全走进了收回分支，
按键等于失灵，已经改掉。）两只手都空才算"空手"：不然右手拿把剑、左手空着也能触发，手感会很怪。

## 决斗盘：收之前先把这一局收拾干净

`DuelSessionManager.reclaimField()` 的顺序（顺序本身有讲究）：

1. **不是本人摆的**（会话绑定的 `ownerId` 是别人）→ 只提醒，不动；
2. **正在决斗**（`isGameStarted() && !hasResult()`，也就是"开了局还没出结果"）→ 只提醒，
   指路右下角菜单里的「投降」。免得手一滑把一局删了；
3. `stop()`：关掉宿主进程 → `clearVisuals()` 收掉场上的卡、手牌和演出（这一步要用 `fieldId`，
   所以必须在清空它之前做）；
4. 忘掉这个盘上的卡组记录（`fieldDecks`）与 `fieldId` / `ownerId`；
5. `field.discard()` 删掉决斗盘实体；
6. 把「决斗盘」物品塞回背包（背包满了就掉在脚下）。

**什么都不丢**：卡盒物品从来没被消耗过（右键只是把卡组的副本登记到盘上），所以收回时卡组的、
人机卡组的选择都还在玩家身上，只是"这场对局的记录"没了。收回之后再放下就是一块干净的新盘。

## 卡盒实体：顺手补的一个丢卡组 bug

原来的 `CardCaseEntity` 是"蹲下右键把卡盒放到地上"（`CardCaseItem.useOn` 会**消耗物品**），
但那个实体右键只会念一遍卡组摘要，**拿不回来**——等于把一副卡组扔在了地上。
现在同一个手势（空手蹲下右键）把它收回：`CardCaseItem.setDeck(stack, deckData)` 把卡组写回物品，
再还给玩家，然后删掉实体。
