# 双人决斗场地资源初稿

这是用于 Blockbench 内查看和编辑的传统决斗垫模型初稿，尚未实现 Minecraft 内的交互、卡片实体、阶段切换或生命值显示功能。

## 文件

- `duel_field_v1.bbmodel`：Blockbench Generic/free 模型源文件。
- `textures/duel_field_atlas.png`：场地纹理。
- `duel_field_layout.json`：区域、方向与卡槽定位数据。
- `duel_field_preview.png`：透视预览。
- `duel_field_top.png`：俯视预览。

## 尺寸与区域

完整决斗垫宽 128、深 112，底板厚 0.75 模型单位，阶段按钮顶部高度为 1.6 单位，按 16 单位对应 1 格换算，平面占地为 8 × 7 格。没有桌腿。推荐单张卡片尺寸为 6.875 × 10 单位，保持 704:1024 卡图比例；每个卡槽外框为 12 × 14，薄边框内净空为 11.24 × 13.24，兼顾竖置、守备横置和素材堆叠。

每名玩家拥有 5 个主怪兽区、5 个魔法与陷阱区、1 个场地区、主卡组区、额外卡组区、墓地区与除外区，共 15 处。双方共 30 处，另有中央 2 个共享额外怪兽区，全场共 32 处。灵摆区与最左、最右魔陷区共用位置。额外怪兽区并非只供 Link 怪兽使用，合法区域与操作由规则引擎判断。

坐标以场地中心为原点，X 为左右，Z 为场地纵深；P1 位于 +Z 一侧，朝向 -Z。以下坐标均为卡槽中心，不表示卡片朝向：

| P1 区域 | X | Z |
| --- | --- | --- |
| 主怪兽区 0–4 | -32、-16、0、16、32 | 18 |
| 魔陷区 0–4 | -32、-16、0、16、32 | 34 |
| 额外卡组 | -52 | 34 |
| 场地魔法 | -52 | 18 |
| 主卡组 | 52 | 34 |
| 墓地 | 52 | 18 |
| 除外 | 52 | 2 |
| 共享额外怪兽区 | -16、16 | 0 |

P2 的个人区域和卡片朝向由 P1 绕原点旋转 180° 得到，即 X、Z 同时取反。共享额外怪兽区只有两个物理位置：P1 的 MZONE 5 对应 P2 的 MZONE 6，P1 的 MZONE 6 对应 P2 的 MZONE 5。

## 后续功能预留

靠近双方玩家的 Z = ±49 控制条预留 DP、SP、M1、BP、M2、EP 阶段按钮、Ready／响应确认和 LP 显示位置。模型中的按钮仅表达位置和外观；阶段切换必须等待规则引擎授权。

模型分组与定位点供后续实体卡槽映射使用，主怪兽区及额外怪兽区上方留空以容纳横置卡片、超量素材和指示物；卡组、墓地及除外区可展示堆叠。手牌继续使用玩家物品栏，不另设台面手牌区。Side 卡组不属于进行中决斗的场地区域。

此资源当前不接入 Forge。完整尺寸超出普通 Java 单方块模型的适用范围，Minecraft 1.20.1 / Forge 47.4.20 后续需采用方块实体渲染，或拆分为多方块结构，并另外实现碰撞、交互与联网同步。
